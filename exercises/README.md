Notes:

- Generated outputs differ between runs. The "expected result" sections describe characteristics to look for, not exact text.
- Answer keys exist only where an exercise says so, and only for this repository's own scenarios.
- Do not paste real confidential data into any exercise.
- Feature availability depends on plan and administrator settings. If a feature is unavailable, do the exercise with the closest alternative and note the difference.
